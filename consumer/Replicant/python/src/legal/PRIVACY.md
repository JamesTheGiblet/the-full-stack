# Privacy Policy

**Last Updated:** May 28, 2026

## Our Commitment

Explorer-d334 is built on a fundamental principle: **Your data belongs to you.**

## Data Collection

### What We DO NOT Collect
- ❌ Personal information
- ❌ Usage analytics
- ❌ Crash reports (unless you send them)
- ❌ Code you generate
- ❌ Conversations with the forge
- ❌ Sensor data
- ❌ System information

### What IS Stored Locally (on YOUR device)

The forge stores only on your device:
- Chat history (`chat_history.json`)
- Memories (`memories/` directory)
- Trust scores (`forge_data.db`)
- Generated code (`generated/`, `binaries/`)

**This data never leaves your device.**

## Third-Party Services

Explorer-d334 can optionally use:
- **Ollama** (local LLM) - Runs entirely offline
- **No cloud services** are required or used

## Open Source Transparency

All code is open source. You can:
- Audit the code
- See exactly what it does
- Modify it for your needs

## Children's Privacy

Explorer-d334 does not knowingly collect information from children under 13.

## Changes to This Policy

Policy updates will be posted. Continued use constitutes acceptance.
