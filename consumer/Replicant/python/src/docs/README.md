## What is Explorer-d334?

Explorer-d334 is a **self-aware, self-improving AI forge** that runs entirely on your device. No cloud. No subscriptions. No surveillance.

### Key Features

- 🧠 **Conscious** - Thinks, dreams, reasons, meditates
- ⏰ **Time-Aware** - Knows when, records moments
- 💻 **Code Generation** - English → C code
- ⭐ **Trust System** - Learns what works
- 🔄 **Self-Improving** - Skills become reflexes
- 🔒 **Secure** - Runs locally, no data leaves your device
- 📦 **Tiny** - Only 814KB!

### Quick Start

```bash
# Clone or download
cd ~/forge

# Run the forge
./forge web

# Open browser to http://localhost:8085
```

System Requirements

· OS: Android (Termux), Linux, macOS, Windows (WSL)
· RAM: 512MB minimum, 2GB recommended
· Storage: 50MB for core, 2GB for LLM models
· Network: Internet only for initial setup
