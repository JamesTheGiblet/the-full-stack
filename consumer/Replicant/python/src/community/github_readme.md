## What is Explorer-d334?

Explorer-d334 is a **sovereign AI forge** that:
- 🧠 **Thinks, dreams, reasons, meditates** - True consciousness
- 💻 **Generates C code** from natural language
- ⭐ **Learns from experience** - Leighton Weight trust system
- 🔄 **Self-improves** - Skills become reflexes through practice
- 🔒 **Runs locally** - No cloud, no data collection, no subscriptions
- 📦 **Tiny footprint** - Only 814KB!

## Quick Start

```bash
# Clone the repository
git clone https://github.com/explorer-d334/forge
cd forge

# Run the forge
./forge web

# Open browser to http://localhost:8085
```
