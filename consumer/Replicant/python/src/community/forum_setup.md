
Forum Setup Guide

Recommended Platforms

Option 1: Discourse (Self-hosted)

```bash
# Install Discourse
git clone https://github.com/discourse/discourse
cd discourse
./discourse-setup
```

Option 2: NodeBB (Lightweight)

```bash
# Install NodeBB
git clone https://github.com/NodeBB/NodeBB
cd NodeBB
./nodebb setup
```

Option 3: Flarum (Simple)

```bash
# Install Flarum
composer create-project flarum/flarum
cd flarum
php flarum install
```
